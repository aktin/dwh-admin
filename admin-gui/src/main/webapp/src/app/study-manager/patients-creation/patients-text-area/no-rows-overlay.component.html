Hilfe

Patientendaten aus Excel einfügen

  • Kopieren Sie die gewünschten Daten aus Excel.
  • Wählen Sie Mit Kopfzeile, wenn die erste Zeile Überschriften enthält, zum Beispiel „Patienten-ID“ oder „Studien-ID“.
  • Wählen Sie Ohne Kopfzeile, wenn die Daten direkt mit einem Patienten beginnen.
  • Alternativ können Sie Strg/Cmd+V verwenden. Dabei wird die erste Zeile als Kopfzeile behandelt.

Welche Daten werden benötigt?

  • Bei automatisch erzeugter Studien-ID: eine Spalte mit {{reference | patientReferenceToLabel}}.
  • Bei manueller Studien-ID: eine oder zwei Spalten mit {{reference | patientReferenceToLabel}} und optionaler Studien-ID.

Patienten manuell hinzufügen

  • Klicken Sie auf , um eine Zeile hinzuzufügen.
  • Doppelklicken Sie auf eine Zelle, um sie zu bearbeiten. Mit entfernen Sie eine Zeile.
